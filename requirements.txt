EMPLOYEE MANAGEMENT SYSTEM
================================

TECH STACK
-----------
Frontend:
- Angular 12+
- Angular Material
- TypeScript

Backend:
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose


FRONTEND SETUP
---------------
1. Open terminal
2. Navigate to frontend folder

cd frontend

3. Install dependencies

npm install

4. Run Angular app

ng serve

Frontend runs on:
http://localhost:4200


BACKEND SETUP
--------------
1. Open terminal
2. Navigate to backend folder

cd backend

3. Install dependencies

npm install

4. Create .env file

MONGO_URI=your_mongodb_connection_string

5. Run backend server

node server.js

Backend runs on:
http://localhost:5000
